자주 묻는 질문

앱을 열었는데 창이 보이지 않아요.

ColorMix Bar는 메뉴바 앱이라 Dock 아이콘과 창이 없어요. 화면 오른쪽 위 메뉴바의 팔레트 아이콘을 누르면 열립니다. 메뉴바 아이콘이 많아 가려졌다면 다른 아이콘을 줄여 보세요.

화면의 색을 가져오려면요?

파란 스포이드 버튼을 누르고 화면에서 원하는 곳을 클릭하세요(취소는 Esc). 찍은 색은 지금 팔레트에 바로 저장되고, 메뉴바 아이콘이 잠깐 그 색으로 바뀝니다. 화면 녹화 권한은 필요 없어요.

원하는 색을 직접 만들 수 있나요?

스포이드 왼쪽의 + 버튼을 누르면 원형 색상표가 나와요. 원 위에서 색을 고르고 밝기 막대로 조절한 뒤 ‘팔레트에 추가’를 누르세요.

색을 복사하려면요?

색 칩을 클릭하면 복사됩니다. 복사 형식(HEX, RGB, HSL)은 설정 › 일반 › 복사 형식에서 고를 수 있어요. 칩을 오른쪽 클릭 › 다른 형식으로 복사를 써도 되고, 칩을 다른 앱의 입력칸으로 끌어다 놓아도 돼요.

색은 어떻게 섞나요?

색 칩을 아래 섞기 접시로 끌어다 놓으세요. 같은 색을 여러 번 놓으면 그 색이 더 많이 섞이고, 접시의 작은 동그라미를 누르면 하나씩 빠집니다. 결과 색을 클릭하면 복사되고 ‘팔레트에 추가’로 저장할 수 있어요. 파랑과 노랑을 섞으면 회색이 아니라 초록이 되는 물감 혼합 방식이에요.

팔레트를 여러 개 쓰고 싶어요.

위쪽 탭 줄의 +로 새 팔레트를 만들고, 탭을 눌러 바꿉니다. 탭을 오른쪽 클릭하면 이름 변경·복제·삭제, 탭을 끌어 다른 탭 위에 놓으면 순서가 바뀝니다.

색을 다른 팔레트로 옮기려면요?

색 칩을 다른 팔레트 탭 위로 끌어다 놓으세요. 또는 칩을 오른쪽 클릭 › 색상 복사 후, 탭이나 칩 판의 빈 곳을 오른쪽 클릭 › 색상 붙여넣기를 누르면 됩니다.

다른 앱을 쓰는 동안 계속 띄워 두고 싶어요.

팝업 제목 오른쪽의 📌을 누르거나, 제목 줄을 잡고 메뉴바에서 멀리 끌면 다른 앱 위에 떠 있는 작은 창이 됩니다. 📌을 다시 누르거나 창을 닫으면 원래대로 돌아가요.

팔레트를 백업하거나 다른 맥으로 옮기려면요?

설정 › 팔레트에서 팔레트를 .json 파일로 내보내고, 다른 맥에서 가져오면 됩니다. 같은 Apple 계정이라면 iCloud 동기화를 켜도 돼요.

iCloud 동기화가 안 돼요.

두 맥 모두 같은 Apple 계정으로 iCloud에 로그인되어 있는지, 앱의 설정 › 일반 › iCloud 동기화가 켜져 있는지 확인해 주세요. 다른 맥에 나타나기까지 몇 분 걸릴 수 있어요. 처음 켜면 iCloud의 팔레트와 이 맥의 팔레트를 합칩니다.

언어나 화면 모드를 바꾸고 싶어요.

설정 › 일반에서 화면 모드(시스템 설정 따름/라이트/다크)와 언어(시스템 설정 따름/한국어/English)를 고르면 바로 바뀝니다.

맥을 켤 때 자동으로 실행되게 하려면요?

설정 › 일반 › 로그인 시 실행을 켜 주세요.

처음 상태로 되돌리고 싶어요.

설정 › 일반 › 초기화에서 ‘완전 초기화’(설정과 팔레트 모두) 또는 ‘팔레트 초기화’(설정은 유지)를 고를 수 있어요. 지운 팔레트는 되돌릴 수 없습니다.

앱을 삭제하려면요?

로그인 시 실행을 켜 두었다면 먼저 끄고, 팝업 아래 ‘종료’를 누른 뒤 응용 프로그램 폴더에서 ColorMix Bar를 휴지통으로 옮기세요.

환불받고 싶어요.

App Store 결제는 Apple이 처리하므로 reportaproblem.apple.com에서 Apple에 환불을 요청해 주세요. 개발자는 직접 환불할 수 없어요.

내 정보는 어디에 저장되나요?

내 맥과, iCloud 동기화를 켠 경우 내 iCloud에만 저장되고 개발자는 볼 수 없어요. 자세한 내용은 개인정보 처리방침을 확인해 주세요.
