ColorMix Bar is built with Apple frameworks (SwiftUI, AppKit, ServiceManagement). Its paint-like color mixing is ported to Swift from the open source project below.

Included

Namespectral.js 3.0.0
Used forColor mixing in the Mixing Dish (Kubelka-Munk theory). The algorithm and reflectance data tables were ported to Swift.
